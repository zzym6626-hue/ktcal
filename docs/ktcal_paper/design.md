# KTCal 软件实验实现（2026-11-05）

依据用户提供的 conference_latex_template (2).pdf，目标是修正现有实现与本版论文的差异，提供训练、前向导出、闭环评估、消融及表格输出。用户已要求直接修改代码，实施采用现有 PyTorch 环境，在工作区制作可验证的改动后迁移至用户指定的 Git 项目 `IdeaProjects/tdtracker`。

## 论文明确规定

- 图2：输入 W=16，2×60×80；ITD通道32/64/128，空间核7/5/5，时间核3×1×1，展平后的每步特征2048。
- 训练Bi-GRU H=128，末步256维直接回归(x,y)，L2损失；训练时还监督前向支路。导出移除反向GRU，FC输入128，微调2轮。
- AdamW lr=0.002，batch16，seed42，确定性cuDNN。
- NCC使用3×3深度可分离特征、局部余弦归一化（公式3）、训练softargmax T=.1，推理hardargmax；L=L_ST+.3 L_match。
- 模板30×25、搜索35×30（本实现统一按宽×高）；tau1=3，tau2=5，sigma=1，confidence=.5。
- Kalman像素坐标下Q=diag(.1,.1,.5,.5)、R=diag(2,2)、重置P=diag(10,10,10,10)。tier2真实异步；tier3同步且强制重置。
- 表I–III：SEET/3ET+2025/Ini-30，目标KTCal分别(p3,p5,p10,d,latency)：(.955,.997,1,1.07,1.06)、(.921,.979,.993,1.44,1.17)、(.861,.923,.974,6.32,2.57)。延迟为RTX3090 FP32，硬件表不在本次软件实现范围。

## 实施决定与不确定性

采用独立 `ktcal_paper` 包，包含按像素单位实现的 Kalman、Python线程异步任务和新的训练入口。保留原STNet和既有权重，以便对照历史实验。数据表示沿用原项目的 Tonic ToFrame + ToBinaRep，删除其改变标签状态的重复坐标启发式。

论文未说明完整epoch数、验证划分、前向辅助损失权重、FC层宽、NCC通道数及详细L_match。本实现明确选择100轮上限、patience20、前向辅助权重1、线性坐标头、NCC16通道，均存入运行配置。ITD沿用图2的4×4逐帧空间池化，不做时间池化。直接输出归一化坐标并以像素尺度计算L2；预测不使用真值或后处理纠偏。其他明确选择：AdamW weight_decay=.01、梯度范数裁剪5、微调lr=.0002；验证以已监督的前向支路平均像素误差选模；NCC用同记录前1–8帧真值模板和末帧±2.5px搜索扰动训练。

现有数据是AIS2024，只有train部分有真标签。按subject固定划分train/val/holdout，切窗前划分，避免同记录泄漏；test占位数据拒绝进入训练和精度评估。AIS使用原10ms标签对齐，不冒充论文4.4ms的3ET+2025实验。旧SEET权重不用于新配置从头训练。

模板与搜索宽高均差5像素，完整有效相关只有6×6响应，位移范围±2.5px，因此内部搜索的epsilon无法达到5px；低置信仍触发同步重定位。此论文几何与阈值的矛盾须在文档中保留，不能暗改搜索范围假装复现。参数量按代码真实统计，不用改核尺寸凑2.28M。

6×6 hardargmax网格没有零位移点，最小位移范数为sqrt(.5)≈.707px；(tau1,tau2)=(4,6)使内部epsilon门控无法触发异步，只有低置信触发同步。论文“去可分离卷积”未给完整核配置，本实现 full_conv 用 (3,Ks,Ks) 替换分离卷积，不能据此认定与论文该行完全一致。

异步结果保留来源帧，收取后从该帧前的Kalman快照回放受影响的后续状态；之前已发出的在线坐标保持不变。此实现不代表论文平台的优化延迟。分别记录帧服务耗时、从到达至在线返回的耗时、含排队的后台实际完成耗时、含回放的结果应用耗时与包含最终清空队列的总墙钟耗时。可用 --realtime 按10ms输入间隔运行，STNet-only使用相同到达时序；默认不等待输入以便测软件处理过程，两种调度的触发/迟到行为可能不同。frame_deadline_misses与async_deadline_misses分别记录在线返回和异步校正实际完成是否错过下一输入bin。

## 验证

单元测试：前向分支导出一致性及不含reverse参数；实际反向梯度到双向头/前向头/NCC；矩形偶数裁剪中心和像素单位；NCC边界/空事件数值；subject划分、窗口不跨记录和占位标签拒绝；tier2异步、tier3强制重置与有限输出。

## 用户授权的双向推理试验

2026-11-05 用户要求先优化3ET，并允许修改结构、使用双向GRU推理。`--inference-mode bidirectional` 保留训练时双向GRU及256维坐标头，不执行前向导出和两轮微调。窗口仍为截至当前帧的连续16帧，双向遍历仅发生在这个历史窗口内部。当前仍按论文取 `out[:, -1, :]`，不会把反向末端单步输出冒称为整窗反向状态。

此模式按验证集 `primary.mean_error_px` 选模；前向模式仍按 `forward.mean_error_px` 选模。推理报告明确记录 inference_mode。完成标记写入最佳权重后才允许评估；中断检查点只用于续训。

`--initialize-from` 新建独立实验，只加载匹配架构、输入规格、NCC规格和同一manifest的模型/NCC权重。保存来源SHA256和原轮数，重新初始化优化器与随机状态，不修改来源实验。初始权重也参与验证选模，避免后续训练变差却丢弃基线。`--resume` 则保持原配置并恢复优化器与RNG。可选余弦调度只用于主训练，逐轮学习率可从保存的epoch和配置重建，最后一轮使用min_lr。

首轮8+2训练得到前向验证7.142px，未经微调的双向为7.451px。保留架构和stride16，仅用更低的余弦衰减学习率进行下一轮16epoch验证收敛试验。没有使用留出集或其他数据集选模；双向结果属于用户授权的实现变体，不能等同于论文前向部署的速度与参数量。

### 可选整窗状态读出

`--readout final_hidden` 将双向GRU的 `h_n[-2]` 和 `h_n[-1]` 拼接后回归当前帧；`last` 保持论文末步输出。旧路径反向GRU的递归权重梯度实测为0（反向支路此时只处理末帧），新路径测试确认该梯度非零。输入仍只含历史窗口，前向辅助支路及导出结果保持一致。

切换读出规则会改变模型行为，即使参数形状相同也作为独立实验记录source_readout/target_readout，训练前的验证分数重新计算。此改动是用户授权的结构试验，不称为论文原结构。报告明确区分readout，是否有精度收益以实际验证结果为准。
